## Getting Started

### Prerequisites
- Modern Browser
- Git Installed

### Installation
- Clone the repository
    ```bash
    git clone https://github.com/VirtualNemesis404/odin-sign-up-form.git
    ```
    
- Navigate to project directory
    ```bash
    cd odin-sign-up-form
    ````

- Open index.html in the browser
